Publishing kit (23 Nov 2026). Needs `npm i framer-api esbuild` and FRAMER_API_KEY.
- `fx.mjs`: connect helper. `css.mjs`: extracts the CSS constant from ThemeToggle.tsx (same text the head code carries).
- `node upload.mjs` uploads the code files and refreshes the head CSS; `node upload.mjs publish` also publishes.
